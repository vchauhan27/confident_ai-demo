# Strict Gates Framework (DAG vs JevEval)

This directory contains the evaluation suite for assessing the agent's outputs using hard, deterministic rules. We maintain two identical use-cases to compare **DAG (DeepAcyclicGraph) metrics** against the new **JevEval model** running in `strict_mode=True`.

## Why Compare DAG vs JevEval?

A DAG evaluates a flowchart of yes/no questions sequentially using an expensive generative LLM. 
By translating the same criteria to JevEval, we evaluate those exact same checklist questions (using `Noul` and `Choice` primitives) in a single parallel pass without generating any text. With `strict_mode=True`, the metric acts as a perfect gate: it returns a hard `1` only if every checklist requirement passes, and a `0` if it fails.

By running both scripts side-by-side, we can observe that JevEval provides the same strict logical gating as a DAG, but significantly faster and cheaper.

| | DAG (`DAG.py`) | JevEval (`DAG-jev.py`) |
|---|---|---|
| **Output** | A hard `0` or `1` | A hard `0` or `1` |
| **How** | Generative LLM judge answers yes/no at each node sequentially | Jev answers calibrated questions in parallel |
| **When it fails** | You know exactly which node failed based on graph trace | You see exactly which question failed in `score_breakdown` |

## Metrics Calculated

### 1. Memory Recall Gate (`DAG.py` & `DAG-jev.py`)

> **Question it answers:** "Did the agent remember what the user said earlier?"

The logic flow:
```text
Did the assistant use the user's name/goal from turn 1 when answering turn 2?
  │
  ├─ No  → score 0 (forgot, hard fail)
  └─ Yes → score 10 (pass)
```

**Input:** A multi-turn conversation (`ConversationalTestCase`) populated dynamically by loading questions from `Data-Generation/multiturn_simulated_goldens.json`.

### Summary

| File | What it checks | Execution |
|---|---|---|
| `DAG.py` | Does the agent **remember** earlier turns? | Sequential generative nodes |
| `DAG-jev.py` | Same as above. | Parallel classification |

---

## How It Is Applied

For multi-turn evaluations, the conversational metric evaluates the agent's latest response against the entire conversation history to check for accurate recall. Both scripts load the simulated conversation generated by the `convo.py` simulator.

- `DAG.py` evaluates this using the **Memory Recall Gate** (via graph nodes).
- `DAG-jev.py` evaluates this using the **Memory Recall Gate (Jev)** (via parallel classification).

## Running

```bash
python DAG.py                  # Generative sequential DAG
python DAG-jev.py              # Parallel classification via JevEval
```
